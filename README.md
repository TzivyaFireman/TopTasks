# ניהול לקוחות ופרויקטים

Node + Express + React. הנתונים נשמרים ב-MongoDB (Atlas, חינמי).

## הרצה מקומית
1. צרי חשבון ב-MongoDB Atlas וצרי אשכול חינמי (M0), ראי להלן.
2. `copy .env.example .env` ומלאי בו את `MONGODB_URI`.
3. `npm install` ואז `npm run dev` ופתחי http://localhost:5173

## MongoDB Atlas (חינם)
1. cloud.mongodb.com ← Create ← אשכול **M0 Free**, אזור קרוב (Frankfurt).
2. Database Access ← משתמש עם סיסמה חזקה (אותיות ומספרים בלבד, כדי למנוע בעיות קידוד).
3. Network Access ← Add IP Address ← Allow access from anywhere (`0.0.0.0/0`). האבטחה נשענת על הסיסמה החזקה, כי ל-Render אין כתובת קבועה בתוכנית החינמית.
4. Connect ← Drivers ← מעתיקים את כתובת החיבור (`mongodb+srv://...`) ומחליפים את `<password>` בסיסמה.
5. אופציונלי: Backup ← גיבויים יומיים.

הערה: אשכול M0 מושהה אחרי 30 יום בלי חיבורים; מפעילים אותו מחדש בלחיצה.

## העלאה ל-Render (חינם)
1. מעלים ל-GitHub (מאגר **פרטי**). חשוב לעשות commit גם ל-`package-lock.json`.
2. ב-Render: New ← Blueprint ← בוחרים את המאגר (קורא את `render.yaml`).
3. ממלאים כשמתבקשים:
   - `MONGODB_URI` – כתובת החיבור מ-Atlas
   - `APP_PASSWORD` – סיסמת כניסה, לפחות 12 תווים
   - `ICS_URL` – קישור ה-ICS מ-Outlook (נשמר רק בשרת, לא נשלח לדפדפן)
4. אחרי הבנייה נכנסים לכתובת שקיבלתם ומתחברים עם הסיסמה.

בתוכנית החינמית השירות נרדם אחרי 15 דקות בלי שימוש, והכניסה הראשונה אחרי שינה לוקחת כדקה. הנתונים נשמרים ב-Atlas ולכן לא נמחקים.

## יומן Outlook
ב-Outlook באינטרנט: הגדרות ← יומן ← יומנים משותפים ← פרסום יומן ← הרשאת "כל הפרטים" ← מעתיקים את קישור ה-ICS. בענן מגדירים אותו ב-`ICS_URL`; מקומית אפשר גם במסך ההגדרות.

## העברת נתונים מהגרסה הישנה (SQLite)
1. בתיקייה הישנה: `npm run export-sqlite` (קורא את `crm.db` ויוצר `sqlite-export.json`).
2. באפליקציה החדשה: הגדרות ← גיבוי ושחזור ← שחזור מקובץ.

## גיבוי
הגדרות ← הורדת גיבוי (קובץ JSON, בלי סיסמאות וקישור היומן). שחזור באותו מסך.
